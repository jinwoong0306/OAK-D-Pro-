# OAK-D Pro 거리 기반 객체 감지 MVP 결과 보고서

## 결과 요약

OAK-D Pro, DepthAI v3, YOLOv6-Nano를 이용해 사람 및 일반 객체를 감지하고,
ROI median depth 기반 거리와 접근 경고를 표시하는 MVP를 구현했다.

## 구현 기능

- RGB 및 stereo depth 실시간 표시
- YOLOv6-Nano COCO 객체 감지: 객체명, confidence, bounding box
- bounding box 내부 ROI median depth 기반 거리 표시
- 5프레임 median filter 및 0.7m 초과 급변값 억제
- 1.2m 이내 접근 시 빨간 화면 경고
- CSV 감지 로그 및 5초 간격 경고 이미지 캡처
- 카메라/XLink 오류 안내와 빠른 실행 스크립트

## 성능 결과

| 조건 | FPS | 결과 |
| --- | ---: | --- |
| 1m 정면 / 일반 조명 | 18.69 | person 감지 성공 |
| 1m / 좌 30도 | 19.05 | person 감지 성공 |
| 1m / 우 30도 | 20.46 | person 감지 성공 |
| 1m / 저조도 | 20.66 | person 감지 성공 |

모든 객체 감지 조건에서 목표 10 FPS를 넘겼다.

## 거리 측정 결론

밝은 환경의 약 1m 정면 구간이 가장 안정적이었다. 0.5m, 2m, 저조도에서는
depth 유효 픽셀 또는 거리 안정성이 낮아 경고 판단에 주의가 필요하다.

현재 거리 측정값은 초기 동작 확인 기준이다. 추후 줄자 기준 0.5m·1m·2m 재측정 후
offset 또는 선형 보정식을 적용하고 경고 임계값을 갱신한다.

## 한계와 후속 개선

### 객체 탐지·거리 측정 정확도 향상 (추후 개발 과제)

- 얇은 노트북·이동 물체에서 depth가 흔들리는 문제 개선
- bounding box 내부의 더 작은 중앙 ROI와 유효 depth 비율·분산 기반 신뢰도 검사 적용
- 신뢰도가 낮으면 거리값 대신 `측정 불안정`을 표시
- 객체 추적 ID별로 거리 필터를 분리해 동일 클래스의 여러 객체가 히스토리를 공유하지 않게 개선
- detection과 depth의 시점 정합을 강화하거나 `SpatialDetectionNetwork` 전환 검토

### 그 외 후속 과제

- 저조도 depth 거리값 재보정
- 실제 측정 거리 기반 보정식 적용
- 대시보드 UI를 영상 영역과 객체 상태 패널로 분리
- 10분 연속 실행 안정성 시험
- 데모 영상 및 발표 슬라이드 제작
